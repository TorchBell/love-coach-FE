# 🚀 Vue.js 갤러리/마이페이지 최종 UI/UX 및 디자인 통일 요구사항 V14

## 1. 개요 및 목표

갤러리 페이지의 '목록 뷰'에서 이미지 상세를 **모달창**으로 변경하여 UX를 개선합니다. 마이페이지에 필요한 **회원 정보 수정 및 탈퇴 컴포넌트**를 추가하고, **회원가입 및 회원 수정 페이지의 디자인**을 웹페이지 전반의 스타일과 완전히 통일시켜 일관성을 확보하는 것이 최종 목표입니다. 모든 작업은 최고의 퀄리티를 목표로 합니다.

## 2. 기술 스택 및 지속적인 요구사항 (유지)

* **프론트엔드:** Vue.js
* **상태 관리:** Pinia (데이터 연동)
* **백엔드 통신:** Axios (데이터 연동)
* **유지보수:** 모든 코드는 **향후 수정이 용이하도록** Pinia 및 Axios 통신 로직을 명확하게 구현하며, 모듈화 및 가독성을 최우선으로 합니다.

## 3. 갤러리 페이지 (`GalleryView.vue`) 최종 수정

### 3.1. 뷰 전환 버튼 텍스트 확정

* **버튼 텍스트:** 뷰 전환 토글 버튼의 텍스트를 다음과 같이 확정합니다.
    * 캐러셀 뷰 상태일 때: **"목록"**
    * 목록 뷰 상태일 때: **"기본"**

### 3.2. 목록 뷰 (`ListView`) 이미지 표시 방식 변경 (모달 도입)

* **캐러셀 뷰:** 기존과 동일하게 **하단에 크게 띄우는 방식**을 유지하며 수정하지 않습니다.
* **목록 뷰:** 목록에서 이미지 아이콘을 **클릭했을 때**, 하단에 띄우는 대신 **모달창**을 사용하여 화면 중앙에 이미지를 **크게** 표시하도록 변경합니다. (모달 내에서 V12의 해금 시스템 로직 구현)

## 4. 마이페이지 (`MyPageView.vue`) 기능 컴포넌트 추가

### 4.1. 회원 정보 수정 페이지 구현

* **요구사항:** 마이페이지에서 **"회원정보 수정"** 버튼을 눌렀을 때, 회원 정보를 수정할 수 있는 **별도의 페이지**로 이동합니다.
* **디자인:** 아래 4.3 항목에 맞춰 **현재 웹페이지 디자인에 맞게** 깔끔하게 구현합니다.

### 4.2. 회원 탈퇴 확인 컴포넌트 구현

* **요구사항:** 마이페이지에서 **"회원탈퇴"** 버튼을 눌렀을 때, 사용자에게 **정말로 회원탈퇴를 하겠는지 묻는** 간단한 확인 컴포넌트(모달 또는 팝업)를 구현합니다.
* **디자인:** 확인 문구 옆에 **작은 이미지**를 넣을 수 있는 공간을 마련합니다. (예정: 토마가 우는 사진)

## 5. 디자인 및 반응형 최종 통일 요구사항

### 5.1. 회원가입/회원 수정 페이지 디자인 통일

* **일관성 확보:** **회원가입 창** 및 새로 구현할 **회원 수정 창**의 디자인이 현재 웹페이지의 **전반적인 디자인 테마와 완전히 일치**하도록 수정합니다.
* **이미지 공간:** 디자인적으로 보기 좋은 공간에 메인 캐릭터 이미지를 넣을 수 있도록 공간을 마련하고 더미 데이터를 삽입합니다.

### 5.2. 반응형 디자인 최종 점검 (V9 요구사항 재강조)

* **요구사항:** 모든 페이지와 새로 추가된 컴포넌트들(회원 수정, 회원 탈퇴 모달)이 창 크기가 작아졌을 때도 **잘 작동하고 UI가 깨지지 않는지** 정확하게 검사하고 수정합니다.

## 6. 최종 검증 및 문서화

* **퀄리티 및 검증:** 모든 작업에 대해 퀄리티를 최우선으로 하여, 코드를 읽고 웹페이지를 켜서 모든 요구사항을 **만족할 때까지** 스스로 체크합니다. (특히 갤러리 뷰 전환 로직, 모달, 디자인 통일)
* **문서화:** 이때까지의 **진행 상황**과 이번 V14에서 **변경된 모든 내용**을 정리하여 마크다운 파일로 작성합니다.
