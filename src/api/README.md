# API 모듈 구조

이 디렉토리는 백엔드 API와의 통신을 담당합니다.

## 파일 구성
- `axios.js` - Axios 인스턴스 및 인터셉터 설정
- `authApi.js` - 인증 관련 API (로그인, 로그아웃, 회원가입)
- `logApi.js` - 활동 기록 API (식단, 근력, 유산소)
- `galleryApi.js` - 갤러리 API (NEW)
- `achievementApi.js` - 업적 API (NEW)
- `npcApi.js` - NPC/대화 API (NEW)
- `questApi.js` - 퀘스트 API (NEW)
